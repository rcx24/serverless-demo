# `padding-estate`

Scenery, and one genuine lateral-movement target.

## Two jobs

**The instances make cross-region discovery legible.** The attack calls
`ec2:DescribeInstances` in four regions. What makes that read as *anomalous* rather than
merely unusual is the contrast: three real workloads in the home region, nothing in
`sa-east-1`. Without an inventory to contrast against, "they looked in four regions" is a
fact the analyst has to be told is interesting.

The instance names appear in `DescribeInstances` output on screen, so they are named after
workloads a finance-platform team would plausibly run.

**The secret makes the orphaned key worth escalating.** `svc-report-runner` — the identity
the attacker mints a key on — is permitted to read this Secrets Manager entry. That
connection is what lets the analyst say *what the uncontained credential could still
reach*, which is the sentence that justifies escalating instead of closing. A persistence
target that can reach nothing is a curiosity.

## Choices that will look odd

**The instances are never started.** A stopped instance appears in `DescribeInstances`
exactly as a running one does, costs only its EBS volume (a couple of dollars a month for
three), and cannot be used for anything by anybody. That is the right trade for scenery.

**`recovery_window_in_days = 0` on the secret.** A secret inside a recovery window blocks
recreation under the same name for up to 30 days, so the second demo of the week would
fail with an error nobody diagnoses quickly. The value is regenerated by the next apply.

**`t4g.nano`, and the SCP enforces it.** The organization's guardrail denies
`ec2:RunInstances` for anything outside a small list of instance types. That is the cost
control that survives a bug in the seed script, which matters in a repository designed to
run unattended in CI.

**IMDSv2 is required.** A demo estate should not fail the check it is demonstrating, and
IMDSv1 is the first thing an auditor looks for.

## The secret is invented

The host is under `.invalid`, which RFC 2606 reserves precisely so it can never resolve,
and the password is a sentence saying it opens nothing.

It is still written to Terraform state, which is why it carries an
`# allow-secret-in-state:` marker — `cli/tests/test_terraform_invariants.py` fails on any
`secret_string` without one. The marker is not a suppression; it is a requirement to say
out loud why a value in state is acceptable.
